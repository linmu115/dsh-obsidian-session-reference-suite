# 普通贴纸创建与切换开销

来源：2026-09-17 当前维护任务中，用户报告“输入内容点击创建后报错”，补充原文“请先迁移此会话的旧贴纸；当前不会覆盖旧数据”，并要求“找到原因并解决”。同一任务报告切换会话和点击侧边栏严重卡顿；后续明确要求提交、推送修复并更新对应项目地图。此处是公开任务内容的摘要，未绑定可展开的原始会话索引。

- 空会话或有无冲突旧贴纸的会话，在首次显式保存时可完成必要迁移并保存新内容；浏览会话不得自动迁移。
- 保留本地/Vault 旧记录、删除意图和版本检查；冲突或连接失败不得继续覆盖保存，输入应保留。
- 同一会话连续保存应串行处理，已经迁移后不重复执行迁移。
- 没有对应标记或选区时不安装全页面几何监听；有内容时保留高亮、滚动与尺寸更新。
- 自动化验证与真实界面效果分开记录，不以测试通过宣称整体卡顿消失。

适用范围是 Sticker Board 0.7.3-rc2.18 的客户端修复，DSH 0.1.5-rc.2。本次不替换 Better Sidebar，也不修改 Maintenance 的旧数据保护合同。
